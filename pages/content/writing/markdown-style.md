# Markdown 문서 작성 규칙

모든 문서는 Markdown으로 작성합니다. 표현을 화려하게 만드는 것보다 구조를 명확하게 드러내는 데 초점을 둡니다.

## 제목

문서 제목은 `#`, 큰 문단은 `##`, 하위 문단은 `###`을 사용합니다. 제목 단계는 순서대로 내려가며 중간 단계를 건너뛰지 않습니다.

## 강조와 링크

중요한 용어는 **굵게**, 가벼운 강조는 *기울임*으로 표시합니다. 코드나 파일명은 `inline code`로 구분합니다.

외부 근거가 있다면 [출처 이름](https://example.com)처럼 의미를 알 수 있는 링크 문구를 사용합니다.

## 코드 블록

언어 이름을 함께 적으면 문서 원본에서도 코드의 성격을 빠르게 파악할 수 있습니다.

```js
const document = {
  title: '기록의 제목',
  category: '개발/웹'
};
```

## 표

표는 항목 간 비교가 필요할 때만 사용합니다.

| 상태 | 의미 |
| --- | --- |
| 초안 | 생각을 수집하는 단계 |
| 검토 | 구조와 근거를 확인하는 단계 |
| 완료 | 다른 사람이 읽을 수 있는 상태 |

## 인용문

> 인용문에는 출처 또는 인용한 이유를 본문에서 설명합니다.
